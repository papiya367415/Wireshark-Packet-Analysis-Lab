
# Wireshark Packet Analysis Lab

This repository documents my hands-on Wireshark packet analysis and network traffic investigation practice as part of my cybersecurity learning journey.

## Objectives
- Learn packet capture fundamentals
- Analyze ICMP traffic
- Understand TCP/IP communication
- Practice filtering network traffic
- Build foundational SOC Analyst skills

## Tools Used
- Wireshark
- Kali Linux
- VirtualBox

## Activities Completed
- Captured live network traffic
- Performed ICMP ping analysis
- Applied display filters
- Investigated source and destination IP addresses
- Examined packet details

## Skills Practiced
- Packet capture
- Traffic filtering
- Basic protocol analysis
- Network troubleshooting
- Cybersecurity lab documentation

## Goal
Develop practical networking and traffic analysis skills for future SOC Analyst and DFIR roles.
